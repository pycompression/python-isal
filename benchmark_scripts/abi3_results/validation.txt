Linux x86_64 validation of the repaired candidate, 2026-11-05

repository's source directory. All standard CPython versions install the same
wheel, isal-1.9.1-cp311-abi3-linux_x86_64.whl; build-metadata.json records the
SHA-256 of each wheel. The checks ran on commit 4451775, whose source is
identical to this revision.

passed, 46 skipped (tests that need _testcapi, tracemalloc, or reference
counts). The tests check that the static types are immutable and not
subclassable, and that Compress and Decompress reject direct calls.

Allocation-failure injection (CPython 3.14.4, _testcapi.set_nomemory): the
nine sweeps in test_output_allocation_failure_cleanup, one per output path,
pass as part of test_stable_abi.py above. Each sweep fails each of the first
80 Python allocations in turn, sees both failures and successful completion,
checks with tracemalloc that a second pass keeps under 8 KiB, and checks a
clean round trip afterwards.
